# Security Policy

## Supported Versions

Until the first stable release, only the latest published alpha version receives security fixes.

## Reporting a Vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub private vulnerability reporting when enabled for this repository.

Include:

- affected version;
- reproduction steps;
- expected impact;
- any suggested mitigation.

The maintainers will acknowledge the report, assess its severity, and coordinate disclosure after a fix is available.
